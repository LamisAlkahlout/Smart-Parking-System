# 🚗 UDST Smart Parking Management System

A campus-wide digital parking management platform developed for the University of Doha for Science and Technology (UDST), designed to streamline parking reservations and improve the overall parking experience for students, staff, and guests.

---

## 📋 Project Overview

This project was developed as part of the **Software Requirements Engineering** course and covers the complete Software Development Life Cycle (SDLC) — from requirements elicitation through to system design, implementation, and testing.

The system allows users to reserve parking spots online, view real-time availability, receive automated notifications, and submit feedback — all through a role-based access platform.

## ✨ Key Features

- Online parking spot reservation and cancellation
- Real-time parking availability display
- Automated notifications and reminders
- Guest reservation support
- Role-based access for Students, Staff, and Administrators
- 5-minute temporary slot lock to prevent double booking
- Automatic release of expired reservations
- User feedback and rating system
